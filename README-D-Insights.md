# Tempo D Learning Feedback and Insights

当前版本：Integrated R5，2026-11-18。本文说明当前工程行为；旧截图和早期设计不是当前验收结果。

## 打开和运行

Android Studio 打开含 settings.gradle.kts 的 Tempo 目录，Sync 后 Run app。本包是源码工程，不含 APK。正常升级使用同签名覆盖安装，保留原数据。演示数据另用空白模拟器，操作见 DEMO-GUIDE.md。

## 当前能力

| 入口 | 行为 |
|---|---|
| Schedule → 任务 → Start focus | 启动、暂停和恢复；进入 Session review 后确认保存 |
| Session review | 保存部分进度或完成；分钟可调整或不记录；难度和剩余时间可选 |
| End without saving | 结束会话并返回日程，不新增反馈；日程可以随当前时间重新计算 |
| Insights → Overview → Log activity | 关联任务的手动补录，包含无耗时完成 |
| Overview / Home → History | 查看最近 200 条明细；总条数与七日分钟独立按全库聚合；更正更新原 ID |
| Insights → Overview | 七日时间、总体完成、日图、类别占比 |
| Insights → Estimates | 同批已完成任务的 MAE，展开 How this is calculated 查看偏差，下方是待办预测 |
| Insights → Patterns | 记录天数、难度和可信计时时段，展开 About these patterns 查看截止日期比较和无时长记录 |
| Home → Yesterday | 按反馈保存日期统计；R4 用执行前原估计及与 D 相同的资格筛选评估已完成任务 |

## 学习和统计口径

- 使用完整任务的实际/原估计比例；比例影响限制在 0.5–3，30 天半衰期，三个中性先验。至少三个同类型样本才采用细类型，否则采用同类别。标题不用于猜测相似性；冷启动使用原估计。
- 第一次开始时固定原估计和系统预测。开始后改变预估、类别或类型，保留快照并排除不再可比的任务；改回去也不恢复该资格。
- MAE 在同一批有资格的已完成任务上比较执行前估计与完整实际总耗时，没有七日限制。手工补录、缺失后补填、范围变化和来源不明的旧更正被排除。
- 从计时进入回顾并调整分钟，仍保留原预测的评价资格；调整后的分钟不作为可信执行区间。正常正数到正数的历史更正保留原有资格，不新增记录。
- Time not recorded 保存 NULL。任何一次活动缺少分钟时，不能把已知部分当作完整任务总耗时。补填后的完整数据可帮助后续校准，但不会恢复 MAE 资格。
- BACKFILLED / CORRECTED 区分补填与正常更正；旧 ADJUSTED 且 revision > 0 的来源不明确，保守排除评价。
- 剩余工作采用明确剩余量，或预测减去已录时间。未完成且剩余量耗尽时保留短块。更正锚点之后的活动调整差额；较早更正不推翻较新的剩余判断。
- Overall completion 包含活动任务和已完成任务；归档的已完成任务保留，归档的未完成任务退出分母。这不是七日日程执行率。
- 七日用时按本地保存日期，包含今天。难度为可选的主观评分。When you worked 只用可信计时运行区间；不是效率评分，不改变高效时间偏好。
- 截止日期比较使用执行前快照和完成日期，独立于分钟是否缺失；未完成的逾期任务不在此分母中。
- Home 准确度采用相同资格任务的原始用户估计，只在任务完成当天计算；无证据时显示缺项，不算作 0% 或 100%。Home 总分按完成 50、记录时间 30、估计 20 汇总，缺项后重分配权重，不是生产力评分。

## 与 B 和 C 的接口

当前数据库为 V4，含归档字段和每周固定时段，支持既有 V2/V3 升级路径。R4 没有更改 schema 或依赖版本。

任务、Profile、反馈及更正等操作通过 AutoScheduler 触发今天起七日重排。记录保存与重排分开：记录保存成功后即使排程失败，也不能重复提交记录。重排保留手动锁定和历史，整周冲突回滚。正在运行的计时会暂缓自动重排。

提前完成取消未来 PLANNED 块，并截短正在占用的时段。归档保留活动和合格历史，永久删除在事务中移除关联数据。C 按 D 的剩余量排程；固定安排不能作为“已实际完成”的反馈自动累计。
