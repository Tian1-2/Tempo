## 功能与入口

| 入口 | 功能 |
|---|---|
| 日程 → 任务 → 开始专注 → Session review | 暂停/继续计时，记录部分进度或完成；用时可调整或不记录，难度可选 |
| Insights → Log activity | 手动补录用时、进度或无耗时完成 |
| Insights → Activity history | 更正最近 200 条活动的用时与难度，更新原记录 |
| Insights | 后续任务估计、剩余工作、七日用时、MAE/Bias、难度、完成和真实计时区间 |
| 新建/编辑任务 → Task type | 可选细分类别；开始后修改工作范围须确认剩余工作量 |

## 学习与统计口径

- 使用完整任务的实际/原估计耗时比例，限制在 0.5–3，以 30 天半衰期加权，并加入 3 个中性先验以降低小样本影响。
- 同类别、同类型至少 3 个完整样本时参考细类型，否则回退类别。冷启动使用用户估计，不承诺精确预测。
- 第一次开始时固定原估计与预测。更改已开始任务的预估、类别或类型后，保留原预测并排除不再可比的学习/MAE 样本。
- 已填剩余值只在新反馈保存时扣减；明确填写新剩余值时以新判断为准。更正锚点之后的记录调整差额，较早记录的更正不推翻后来的剩余判断。
- Time not recorded 保存 NULL，不制造分钟。任何一条活动缺少用时，就不把部分已知分钟当作完整任务总耗时。
- 补填后完整耗时可以用于未来学习，但不进入 MAE；原有耗时清空后再补填也不恢复 MAE 资格。
- 正常更正已有正数耗时可保留原评价资格；原预测与完成时间不被改写。
- MAE 使用执行前固定预测和同一批任务的实际总耗时。手动补录、缺时/后补时间、范围变化及来源不确定的旧更正排除。
- V8/V8.1 的 ADJUSTED + revision > 0 无法区分正常更正与缺时补填，保守排除出 MAE；记录和完整用时学习保留。新版本用 BACKFILLED / CORRECTED 区分来源，不改 schema。
- Deadline comparisons 单独使用原有执行前快照与完成时间证据，不因缺失/补填耗时移除已成立的比较。未完成逾期任务不在其分母中。
- Overall completion 为全部已保存任务状态比例，不是每日计划完成率。
- 七日用时按活动保存日期聚合，包含今天；手动录入的保存时间不冒充实际执行时刻。
- When you worked 仅统计可信计时运行区间，暂停、手动及调整后的分钟不计入。四段为 Overnight 00–06、Morning 06–12、Afternoon 12–18、Evening 18–24，显示分钟向上取整。这是活动分布，不是效率评分，不自动影响高效时间偏好。

## 与排程、数据库的接口

- D 更新任务预测及剩余工作；C 使用这些分钟生成单日日程。保存反馈/更正不会自动重排整个日程。
- 提前完成时取消未来 PLANNED 块，当前块未使用尾部截到下一整分钟。CANCELLED 行作为历史保留，但生成、手动冲突检查、手动固定分钟数和日程计数均忽略它们。
- `planning/ScheduleEditRules` 是页面实际调用的手动调整检查；数据库 DAO 仍做最终验证。
- 本工程数据库 **V3**，支持 V1/V2 的 D 表增量升级。B 的四张原表结构不变，新增 D 快照、提交回执、活动元数据与计时区间表。
- 保存回执避免重复 session，更正使用 revision 拒绝过期页面写入；事务保证记录、状态、剩余量和预测更新一致。
